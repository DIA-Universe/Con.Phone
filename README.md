# Con.Phone

노트북에 연결된 키보드·마우스를 Android(갤럭시)와 iPhone으로 공유하는 Windows용 무선 입력 프로젝트입니다.

## 고정 조건

- 추가 USB/Bluetooth 동글 없이 노트북 내장 Bluetooth를 사용합니다.
- Android와 iPhone을 함께 대상으로 합니다. 첫 실기기 검증 대상은 갤럭시입니다.
- iPhone 실기기 테스트는 아직 수행하지 않았습니다.
- 외부 서버, 계정, 데이터베이스, 입력 내용 수집을 사용하지 않습니다.
- 원격 입력은 명시적으로 승인한 연결에만 전송하며, 오류 시 로컬 입력으로 복귀합니다.

현재 초기 구현 중입니다. 빌드·자동 테스트·실기기 검증 여부는 각각 구분해 기록합니다.
