# Con.Phone 0.3.1 input and clipboard fixes

Reported device: Galaxy S25+. Reported failures: jerky mouse, F9 return not working, clipboard failing both directions.

## Changes

- Pointer pacing measures start-to-start time so the awaited Bluetooth notification does not incur another full interval. Motion accumulated during the pacing wait is coalesced before encoding, without crossing key/button/scroll/target boundaries. Negative displacement cannot merge beyond the HID descriptor limit.
- F9 emergency return accepts extra held modifiers and shortcuts generated by keyboard utilities. F8 return releases local input immediately. A separately registered Windows emergency hotkey provides a fallback if the low-level hook is unavailable. Bluetooth maintenance no longer holds the UI action gate.
- Windows sends clipboard updates while PC input remains active, keeps failed generations pending, and retries after the companion connects. Only one automatic send is in flight. The sync checkbox applies immediately and the clipboard page shows the active target channel state.
- Android performs MTU negotiation before service discovery, serializes characteristic reads against writes, reconnects on stalled setup/read/write operations, ignores callbacks from old connections, and requests high connection priority. The foreground screen shows actual service status.
- Android captures outgoing clipboard data while its activity has focus and stages it in the existing durable share queue. Returning to the companion sends the copied item; incoming Con.Phone items are excluded from automatic echo. Android does not permit arbitrary background clipboard reads; use the companion screen or Share → Con.Phone from another app.
- Windows 0.3.1 and Android versionCode 4/versionName 0.3.1. HID report map and Android signing identity are unchanged.

## Acceptance on the phone

1. Install the new APK over 0.3.0 and tap PC connection start. Keep existing Bluetooth pairing.
2. Verify the PC has the Galaxy registered/active and clipboard sync enabled. Confirm the companion's connection status progresses past service discovery.
3. Move/drag/scroll for 60 seconds. Press F9 alone and while Ctrl/Shift is held; PC input should resume immediately. If the keyboard emits media keys, check Fn+F9/Fn Lock.
4. Copy fresh text on PC without switching input; paste on phone. Copy text on phone, reopen Companion, then paste on PC. Repeat with a small image and Share → Con.Phone.
5. Disconnect/reconnect Bluetooth and repeat. Large images still require the existing P2P permissions/firewall path.
