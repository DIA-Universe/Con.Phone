# LINKO 1.0.3

## Teams 복사

기존에는 Unicode 일반 텍스트만 읽어서 HTML만 있는 클립보드 항목을 건너뛰었습니다. 일반 텍스트를 우선 읽고, 없으면 CF_HTML의 선택 영역에서 텍스트를 추출합니다. 한글·이모지의 UTF-8 바이트 오프셋, 문단/줄바꿈과 표의 셀 경계를 처리하며 스크립트·이미지·스타일은 전달하지 않습니다. HTML을 실행하거나 외부 리소스를 요청하지 않습니다. 변환 결과도 기존 1 MiB 텍스트 제한을 따릅니다.

이는 Teams가 HTML만 제공하는 경우의 처리입니다. 실제 사용자 Teams의 클립보드 형식은 아직 확인되지 않았습니다. Teams에서 복사한 내용이 PC 메모장에도 붙여넣어지지 않는 경우에는 Teams 측 복사 자체를 별도로 확인해야 합니다.

Windows는 메시지 전용 창에서 전역 클립보드 알림을 받습니다. LINKO 창 포커스는 조건이 아닙니다. 다른 프로세스의 일반 텍스트/HTML 쓰기를 감지하는 검사를 추가했습니다. 읽는 중 원본이 바뀌면 새 항목을 다시 읽고, 일시적인 클립보드 점유에는 최대 약 4.5초 재시도합니다.

## BLE 텍스트 전송

텍스트에도 조각별 수신 확인과 재전송을 적용합니다. 조각 유실이나 마지막 적용 ACK 유실을 복구하며, 재전송된 마지막 조각은 APK가 캐시된 ACK로 응답하여 중복 적용하지 않습니다. 세 번 실패 후 영구 중지하던 경로는 최대 60초 간격의 자동 재시도로 바꾸고, 새 복사/채널 재연결 시 대기를 해제합니다. 전송 시간 제한은 45초이며 새 복사가 들어오면 이전 항목은 취소합니다.

연결 로그에는 클립보드 채널 연결 여부와 알림·캡처·읽기 오류 개수만 추가합니다. 복사 내용은 진단 로그에 넣지 않습니다.

## iOS: 단축키로 잠금 후 PC 복귀

마우스 버튼 잠금 방식은 제공하지 않습니다. PC의 기존 **휴대폰 잠금 + 복귀** 단축키(기본 Ctrl+Alt+L)를 누르면, Apple 프로필에서는 **iOS로 보내는 잠금 키**(기본 F12)를 전송하고 PC 입력으로 복귀합니다. 이 키는 LINKO 입력 설정에서 바꿀 수 있습니다.

1. PC LINKO 입력 설정에서 **Apple 권장값**을 선택합니다.
2. iPhone의 **설정 → 손쉬운 사용 → 키보드 → 전체 키보드 접근 → 명령 → 화면 잠금**을 엽니다.
3. 등록 화면에서 F8로 폰 조작에 들어간 뒤 F12를 눌러 화면 잠금 키로 지정합니다. 사용자화한 경우 LINKO와 iPhone에 같은 키를 지정합니다.
4. 이후 PC의 **Ctrl+Alt+L**로 잠금을 요청하고 PC로 돌아옵니다. F9는 기존대로 PC 복귀입니다.

Control+Command+Q를 iPhone 공통 기본 잠금 키로 가정하지 않습니다. iOS 설정 변경은 PC HID에서 자동으로 할 수 없어 휴대폰에서 한 번 지정해야 합니다. 키 조합을 사용자화하면 Apple 프로필의 Ctrl/Command 교환이 일반 입력과 동일하게 적용됩니다. F12 단독은 이 교환의 영향을 받지 않습니다. HID 전송 성공은 화면 잠금 성공의 확인이 아닙니다.

[Apple 외장 키보드 명령 사용자화](https://support.apple.com/guide/iphone/control-iphone-with-an-external-keyboard-ipha4375873f/ios)

## 검증

Core HTML 변환/기존 입력·전송 회귀 검사, Windows HTML-only DataObject·일반 텍스트 우선순위·iOS 단축키 인코딩·릴리스 검사, Android 텍스트 조각 유실/ACK 재전송 검사와 로컬 APK 빌드를 수행했습니다. 실제 Windows 클립보드 검사는 초기 스냅샷 읽기에서 OS 오류 `0x800401D0`로 차단되어 외부 프로세스 왕복까지 실행하지 못했습니다. 실제 Teams 복사와 iPhone 화면 잠금은 사용자 기기에서 확인이 남습니다.

EXE/APK는 모두 1.0.3(Android versionCode 13)입니다. 이미지 전송은 계속 지원하지 않습니다.
