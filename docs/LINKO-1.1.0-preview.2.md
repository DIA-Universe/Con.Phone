# LINKO 1.1.0-preview.2 — Bluetooth 안정화 전용

화면 가장자리 자동 전환을 제거하고 Bluetooth와 입력 안정성 개선만 남겼어요. **F8로 휴대폰 조작을 시작하고 F9로 PC에 돌아와요.** 단축키를 바꿨다면 설정한 키를 사용해 주세요.

## 다운로드와 적용

- [Windows EXE](https://github.com/DIA-Universe/Con.Phone/releases/download/v1.1.0-preview.2/LINKO.exe)
- [EXE SHA-256](https://github.com/DIA-Universe/Con.Phone/releases/download/v1.1.0-preview.2/LINKO.exe.sha256)
- [공개 소스](https://github.com/DIA-Universe/Con.Phone/tree/v1.1.0-preview.2)
- [선택 사항: Android 클립보드 APK](https://github.com/DIA-Universe/Con.Phone/releases/download/v1.1.0-preview.2/LINKO-1.1.0-preview.2.apk)

기존 LINKO를 **트레이에서 종료**한 뒤 새 EXE를 실행해 주세요. X로 닫으면 트레이에 남아 있어요. 페어링과 기존 키보드·마우스 설정은 유지해요. 휴대폰을 선택하고 **이 기기 사용**을 누른 뒤 F8로 전환하면 돼요.

키보드·마우스 사용에 휴대폰 앱은 필요하지 않아요. Android APK는 선택적 클립보드 앱이며 이번에는 버전만 맞췄어요. PC의 안정성 변경은 EXE 교체로 적용돼요.

## 변경한 내용

- 자동 전환 UI, 가장자리 감지, 좌표 추정, 보정, 커서 강제 이동 코드를 제거했어요. 이전 preview.1에서 자동 전환을 켰어도 다시 작동하지 않아요. 저장된 이전 설정은 읽을 때 무시해요.
- PC를 사용하는 동안에는 자동 전환을 위한 원시 마우스 처리를 하지 않아요. Bluetooth가 준비돼도 사용자가 전환 버튼이나 단축키를 누를 때만 휴대폰 입력을 시작해요.
- Windows 입력 훅에서 Bluetooth·UI·로그 처리를 기다리지 않아요. 처리기가 막히거나 대기열이 넘쳐도 PC 입력을 다시 통과시키며, F9 복귀는 전송 처리기가 막혀 있어도 바로 적용돼요.
- 입력 전송 대기를 기존 정식 버전의 3초에서 500ms로 줄였어요. 오래된 대기 입력과 이전 전환 세대의 작업을 버리고, 취소를 무시하는 비동기 전송도 무한히 기다리지 않아요. OS 스케줄링까지 포함한 절대 500ms 응답 보장은 아니에요.
- 연결 상실 시 UI를 기다리지 않고 PC 복귀를 시도해요. 휴대폰에 키·버튼 해제를 전달하지 못했으면 같은 기기의 로컬 상태에서 재시도해요. PC 복귀를 반복해도 남은 해제 요청을 잃지 않도록 보완했어요.
- 전환할 때마다 입력 훅이나 Bluetooth 서비스를 다시 만들지 않아요. 활성 연결이 있거나 최근 5초 안에 상대 활동이 있으면 검색 신호 오류에 따른 서비스 재게시를 보류해요. 늦게 도착한 관찰값이 이 대기 구간을 줄이지 않도록 보완했어요.
- 클립보드를 꺼 둔 설정을 재시작 후에도 유지해요. 끄는 순간 기존 GATT 서비스를 재구성하지 않고 전송을 중단해요. 꺼진 상태로 시작하면 선택적 클립보드 서비스를 만들지 않아요.
- Windows 잠금·절전 시 입력만 PC로 돌리고, 복귀나 재연결 후 휴대폰 입력을 자동으로 재개하지 않아요. 로그는 비동기로 기록하며 입력한 키와 클립보드 본문은 남기지 않아요.

## 검증과 남은 확인

- Core **206개 통과**. 전송 제한, 대기열 순서·전환 세대 분리, 재게시 대기 구간과 늦은 콜백을 확인했어요.
- Windows 전체 검증 통과, Release 빌드 경고·오류 0. 입력 처리기가 막힌 동안 PC 입력 통과와 F9 즉시 복귀, F8 수동 복귀, 기존 자동 전환 설정 무시를 확인했어요.
- Windows 단축키·설정 유지·UI 종료/복구·실제 클립보드 왕복·게시 EXE 실행 검사 통과. 화면을 렌더링해 자동 전환 설정이 제거된 것도 확인했어요.
- 네이티브 Bluetooth 복구 검사 통과. 연결 관찰값을 주입한 100회 상태 확인에서 서비스 재게시를 억제하고, 연결 종료 후 복구 및 반복 실패 시 대기를 확인했어요. 실제 휴대폰 연결 검사는 아니에요.
- Android JVM **52개 통과**, 실패·오류 0. APK 빌드 성공.

**실제 Android·iPhone 연결에서 장시간 끊김과 다른 앱 새로고침이 개선됐는지는 아직 검증하지 못했어요.** 따라서 테스트 릴리스로 배포하고, 이 증상이 완전히 해결됐다고 단정하지 않아요. 이번 기능에 필요하지 않은 별도 iOS 동반 앱에는 기존 컴파일 오류가 남아 있어요.

문제가 남으면 발생 시각과 PC **도움말 → 진단 파일 저장**을 함께 확인해 주세요. Android에서는 동반 앱을 강제 종료하고 PC 클립보드를 끈 경우와, 동반 앱·클립보드를 켠 경우를 나눠 비교해요. 앱 화면만 닫아도 백그라운드 서비스는 남을 수 있어요.
