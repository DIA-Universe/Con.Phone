# LINKO 1.0.13 — Bluetooth 연결 상태 조회와 HID 표시 갱신

사용자는 1.0.12에서 페어링 기기는 표시되지만 연결해도 ‘연결됨’으로 바뀌지 않는다고
보고했습니다. 1.0.12의 목록 복구는 실제 입력 재연결 문제를 해결한 것으로 확인되지 않았습니다.
현재 로컬에는 해당 장애 로그나 연결된 ADB 휴대폰이 없습니다.

## 코드에서 확인한 누락

Windows 페어링 목록 조회는 `System.Devices.Aep.IsConnected`를 요청하지 않았습니다.
`Peer.Connected`는 활성 키보드 또는 마우스 구독 여부로만 계산됐습니다. 따라서 Bluetooth
링크가 연결됐지만 HID가 준비되지 않은 경우를 페어링 상태와 구분해서 표시할 수 없었습니다.
이 코드 누락은 확인했지만, 사용자의 HID 구독이 복구되지 않는 원인은 아직 확인하지 못했습니다.

## 변경

- paired-only 메타데이터 조회에서 Windows의 Bluetooth 연결 상태를 읽습니다. 값이 없거나
  조회가 실패하면 Unknown으로 취급하며 이전 ‘연결됨’ 값을 재사용하지 않습니다.
- ‘Bluetooth 연결됨 · 키보드·마우스 입력 연결 대기’와 ‘Bluetooth 연결됨 · 입력 준비됨’을
  구분합니다. 활성 HID 구독 자체도 현재 입력 연결의 증거로 사용합니다. Bluetooth 메타데이터만으로
  입력 전송을 허용하지 않으며 기존 페어링/승인/HID 준비 조건은 유지합니다.
- HID 구독 변경 때 즉시, 이후 기존 750ms UI 타이머에서도 현재 입력 상태를 행에 적용합니다.
  이름/페어링 조회를 기다리는 동안 입력 표시가 멈추지 않습니다. UI의 선택 기기는 유지합니다.
- Bluetooth 메타데이터는 HID 서비스 시작 여부에 상관없이 기존 5초 주기로 갱신합니다.
  HID Suspend 상태도 구분해 실제 입력이 일시 중지된 기기를 ‘준비됨’으로 표시하지 않습니다.
- 진단 파일과 도움말에 OS 연결 상태, 활성 HID, Suspend, 선택 여부, 기기 지문을 함께 기록합니다.
  원본 Bluetooth 주소나 클립보드 내용은 추가하지 않습니다.
- 이번 변경은 조회/표시에 한정됩니다. 세션 정리/재생성, 연결 재시도, HID 보고서 형식,
  페어링, F9 처리와 Android 연결 코드는 변경하지 않았습니다.

## 검사와 한계

- Windows Release 빌드: 경고/오류 0개.
- 목록/상태 검사 21개 통과. 테스트 입력으로 OS 연결 false → true → 조회 실패 → false,
  HID 없는 연결, 부분 HID, HID 복구, Suspend/해제, 지연 조회 중 단절을 검증합니다.
- 실제 Windows paired-only API: 로컬 후보 5개의 연결 속성을 읽었습니다.
  당시 5개 모두 disconnected, unknown 0개였습니다. 실제 휴대폰의 연결 전환 검사는 아닙니다.
- 실제 WinForms ListBox 검사 3개: 선택 유지, 입력 대기→준비, Suspend, HID 소실 시
  별도 Bluetooth 상태 보존. BLE 서비스 시작/클립보드 수집 없이 실행합니다.
- Android는 버전 1.0.13/versionCode 23으로 맞추며, 최종 APK 빌드/단위 검사 결과는 릴리스에 기록합니다.
- **실제 휴대폰의 물리 연결/입력 복구와 장시간 끊김·마우스 지연은 미검증입니다.**
  이 빌드를 입력 재연결 문제가 해결된 버전이라고 표현하지 않습니다.

## 적용과 남은 진단

PC 트레이에서 LINKO를 종료하고 1.0.13 EXE로 실행합니다. 이번 수정에 휴대폰 앱 재설치나
기존 페어링 삭제는 필요하지 않습니다.

사용자에게 현재 실행 중인 버전의 **도움말 → Bluetooth 진단 보기 → Bluetooth 다시 검사**에서
키보드·마우스의 OS 구독/활성/선택 기기 수를 요청했습니다. OS 구독이 없는 상황과,
구독은 있으나 세션 상태나 선택 기기 매칭이 어긋난 상황을 구분해야 다음 연결 수정이 가능합니다.

Windows 속성 정의: [System.Devices.Aep.IsConnected](https://learn.microsoft.com/en-us/windows/win32/properties/props-system-devices-aep-isconnected).
