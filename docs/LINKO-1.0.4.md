# LINKO 1.0.4

자동 텍스트 동기화는 계속 켜져 있습니다. 작은 텍스트에도 마우스 입력 우선 처리를 적용합니다. PC에서 마우스 이동을 감지하면 BLE 클립보드 데이터 알림마다 48ms를 양보하며, 최초 전송·조각 재전송·최종 적용 확인 재전송에 동일하게 적용합니다. 움직임이 이어져도 전송을 무기한 멈추지 않습니다. 입력이 없을 때는 이 추가 지연을 적용하지 않습니다.

이미 보낸 마우스 보고서 대신 입력이 들어온 시점으로 활동 여부를 판단합니다. Bluetooth 전송이 밀려도 입력 우선 처리가 빠지지 않도록 하기 위한 변경입니다. P2P 전송 및 HID 전송 주기는 변경하지 않았습니다.

이 변경은 확인된 전송 경합 가능성을 줄입니다. 실제 휴대폰 끊김 원인이 확정되거나 해결이 검증된 것은 아닙니다. 기존 16ms pacing 안내는 최적화 요청을 적용하지 못했을 때의 기본값 안내이며 무선 장애를 진단한 로그가 아닙니다.

Core 132개 검사(연속 입력 중 진행, 유실 재시도마다 양보, 취소, 유휴 시 추가 지연 없음 포함)와 Windows 빌드 통과. 실제 Bluetooth 지연과 Galaxy/iPhone 마우스 부드러움은 기기 확인이 필요합니다. 이전 iOS F12 잠금 설정과 Teams HTML 텍스트 처리는 유지합니다. 자세한 설정은 [1.0.3 안내](LINKO-1.0.3.md)를 참고하세요.
