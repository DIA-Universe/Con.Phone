# LINKO 1.0.15 — 연결 중 복구 요청과 Android 화면 재생성 줄이기

## 적용

PC 트레이에서 기존 LINKO를 **종료**한 뒤 새 `LINKO.exe`를 실행하세요. 창의 X는 트레이로 숨깁니다. Android LINKO를 사용한다면 `LINKO-1.0.15.apk`도 덮어 설치하세요. EXE만 교체하면 Android 화면·알림 수정은 적용되지 않습니다. iPhone/iPad의 HID 사용에는 APK가 필요하지 않습니다. 페어링과 저장된 설정은 유지합니다.

## 확인한 코드와 변경

- Windows는 광고 상태가 중단됐다고 나오면 실제 연결 여부와 관계없이 약 4초마다 HID 게시를 재요청했습니다. 클립보드 서비스의 실패도 1.5초 상태 확인 주기마다 재시도할 수 있었습니다. 이제 HID 또는 클립보드의 활성 세션이 있으면 자동 재게시를 보류합니다. 키보드·마우스 구독이 완성되기 전의 HID 읽기/쓰기 세션도 관찰하므로 초기 설정이나 입력 일시 중지 중인 연결도 보호합니다.
- 연결이 없고 게시에 계속 실패하면 재시도 간격을 4·8·16·32·60초로 늘립니다. 상한은 60초이며 정상 게시 또는 활성 연결이 확인되면 초기화합니다. 수동 시작과 명시적인 종료는 기존대로 동작합니다. 선택적 클립보드 서비스의 최초 준비가 실패했더라도 HID 연결 중 상태 확인 타이머가 새 서비스를 추가하지 않습니다. 연결이 끝난 뒤 자동 복구를 재개합니다.
- Android에서 실제 `STATE_DISCONNECTED`가 도착했을 때 이미 끊긴 GATT에 다시 disconnect 요청을 보내지 않습니다. 로컬 객체는 한 번만 닫고 기존의 단일 재연결 예약과 횟수 제한을 유지합니다. 사용자가 직접 해제하는 경로는 disconnect/close를 수행합니다.
- Android의 홈·설정·업데이트·공유 화면은 `keyboard|keyboardHidden|navigation` 변경을 직접 수용합니다. LINKO 화면이 외부 입력 장치 상태 변화만으로 다시 만들어지지 않습니다. 화면 회전·언어 변경 같은 다른 구성 변경 처리는 유지합니다. 이 변경으로 다른 회사의 Android 앱이 구성 변경을 처리하는 방식까지 바뀌지는 않습니다.
- 상태 문구가 바뀔 때만 홈 표시를 갱신합니다. 포그라운드 알림은 최초 한 번 시작하고, 같은 요약은 다시 보내지 않으며 변경 알림에도 재알림을 억제합니다. 앱을 다시 열 때 정상 상태를 임시 연결 요청 문구로 덮어쓰지 않습니다.
- 공개 소스에서 빌드를 재현할 수 있도록 오래된 0.3.0 고정 버전·주변 HID 검색·이미지 공유 검사와 CI의 예전 EXE 파일명을 현재 제품에 맞췄습니다. Windows/Android 버전 일치, 선택한 페어링 PC만 연결, 텍스트 공유 정책은 계속 검사합니다.

광고 상태는 실제 연결 해제를 뜻하지 않습니다. 위 경로는 코드로 확인하고 제어된 상태를 주입해 검사했지만, 사용자의 원래 장애 원인을 실기기 로그로 특정한 것은 아닙니다.

## 검증

- Core 동작 검사 **197개 통과**. 재시도 시간 경계·상한·초기화, HID/클립보드 공동 세션 관찰을 포함합니다.
- Android JVM 검사 **52개 통과**, 실패/오류 0. 원격 해제 후 중복 disconnect 방지와 수동 해제 도중 원격 해제가 도착하는 경우를 추가했습니다.
- Windows Release 빌드 경고/오류 0. APK 빌드 성공, 패키지의 네 Activity 모두 구성 변경 비트 `0x70`을 확인했습니다.
- 실제 Windows GATT provider에 광고 상태와 연결 관찰값을 주입한 검사: 100회 상태 확인 및 반복 시작에도 연결 중 재게시 0회, 연결 종료 후 게시 재개, 반복 게시 실패 시 대기, 기존 provider 유지 확인. 실제 휴대폰 연결을 모사한 결과로 취급하지 않습니다.
- Windows 네이티브 서비스 생성/게시/정리 **20회 통과**. 단일 EXE에서도 서비스 수명·복구·릴리스 검사를 실행했습니다.
- 기기 목록, 입력 전환 대기, 단축키 범위, WinForms 종료, 프로세스 재시작 검사 통과. 소스 정합성 검사와 Actions 문법 검사 통과.
- 저장소의 모든 Git 참조를 비밀정보 탐지기로 검사했습니다. 공개에 포함하지 않는 로컬 첨부·로그·빌드 산출물은 Git 제외 대상으로 유지합니다.

실제 휴대폰은 연결되지 않은 상태였습니다. 물리 Bluetooth 끊김 감소, 다른 앱의 화면 깜빡임, 30분 연속 입력과 절전 복귀는 **실기기 미검증**입니다. 이 빌드를 해당 증상의 완전한 해결로 단정하지 않습니다.

## 실기기 확인 순서

1. 양쪽 새 버전을 적용하고 기존 페어링으로 연결합니다.
2. LINKO와 평소 사용하던 휴대폰 앱을 번갈아 열어 화면이 다시 그려지는지 확인합니다.
3. PC 입력과 휴대폰 입력을 전환하며 30분 사용하고, 휴대폰 잠금/해제와 Bluetooth OFF/ON 뒤 재연결을 확인합니다.
4. 증상이 남으면 PC **도움말 → 진단 파일 저장**, Android **설정 → 연결 진단 로그 공유**에서 발생 시각과 함께 확인합니다. 로그에는 클립보드 내용이나 입력한 키를 넣지 않습니다.
