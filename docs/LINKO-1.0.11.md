# LINKO 1.0.11 — 재연결 후 이전 세션 정리 보강

> 후속 사용자 보고: 업데이트 후 ‘사용할 휴대폰 선택’에서 기기가 사라짐.
> 1.0.11 사용을 권장하지 않습니다. [1.0.12](LINKO-1.0.12.md)에서 목록 조회의
> 세션 정리를 제거하고 페어링 기록을 별도 후보로 표시합니다. 아래는 당시 수정/검증 기록이며,
> 실기기 문제가 해결됐다는 뜻이 아닙니다.

사용자는 휴대폰 Bluetooth가 다시 연결된 뒤에도 PC가 계속 ‘연결 확인 중’이라고
표시한다고 보고했습니다. 이 문구의 실제 조건은 현재 목록에서 키보드·마우스 중
한쪽만 활성 구독으로 읽히는 경우입니다. 휴대폰의 Bluetooth 연결 표시만으로
두 HID 보고서의 구독이 복구됐다고 판단하지 않습니다.

## 확인한 코드 문제와 수정

- 이전 HID 추적 기록은 Closed 이벤트 또는 새 구독 callback에 의존했습니다.
  주기적으로 현재 구독 목록을 읽어도 오래된 추적 기록을 대조·제거하지 않았습니다.
  이제 완전히 읽힌 구독 목록에서 사라진 기록과 비활성 세션을 정리하고, 현재 구독에서
  이벤트 추적을 다시 설정합니다. 일부 조회가 실패한 경우 이를 ‘구독 없음’으로 간주하지 않습니다.
  동시 조회의 이전 스냅샷은 더 최신 정리를 덮어쓰지 못합니다.
- 원격 Closed 알림 처리에서 `GattSession.Dispose`가 호출될 수 있었습니다.
  native 세션이 다시 활성화되는 시점과 겹치면 새 연결에 영향을 줄 여지가 있습니다.
  원격 연결 종료/구독 소실은 이제 논리 연결 세대와 이벤트 참조만 정리하고 native Close를
  호출하지 않습니다. 동일 객체를 다시 사용해도 이전 세대의 늦은 해제가 새 세대를
  제거하거나 닫지 않습니다. HID와 클립보드에 함께 적용했습니다.
- 이전 연결의 protocol/suspend 및 읽기용 키·버튼 상태도 지웁니다. 새 연결의 승인은 유지합니다.
  서비스 명시적 정지/종료 처리와 기존 GATT 서비스는 유지합니다.
- 목록의 키보드·마우스·연결 여부를 일관된 값으로 표시합니다. ‘연결 확인 중’ 대신
  ‘키보드 연결됨 · 마우스 입력 연결이 복구되지 않았어요’처럼 부족한 입력을 표시합니다.
  구독이 실제로 없는 상태를 연결 성공으로 표시하지 않습니다.
- Windows **도움말 → Bluetooth 진단 보기 → Bluetooth 다시 검사**와 저장한 진단 파일에
  키보드/마우스의 OS 구독 수, 활성 구독 수, 선택 기기 구독 수, 추적 세션 수를 추가했습니다.

1.0.10의 클립보드 timeout/광고 오류 시 HID 연결 유지 수정은 포함됩니다.
Android는 1.0.10과 연결 동작이 같고, EXE/APK 버전을 맞추기 위해 1.0.11로 함께 빌드합니다.

## 검증과 한계

- .NET 178개 검사 통과. 기존 검사는 서로 다른 native 객체의 재연결을 주로 다뤘습니다.
  이번에는 같은 객체가 비활성→활성으로 돌아온 뒤 이전 HID/클립보드 참조가 늦게 정리되는
  경우, 종료 알림 없이 구독 목록에서 사라지는 20회 사이클, 동시 참조 정리 100개를 추가했습니다.
- Windows Release 빌드, 광고 오류 주입 검사, 실제 GATT 서비스 생성·광고·정리 20회,
  WinForms 종료 및 단축키 범위 검사를 수행합니다. 최종 결과는 릴리스 노트에 함께 기록합니다.
- Android의 연결 동작은 변경하지 않았으며 기존 50개 검사와 APK 빌드를 수행합니다.
- 실제 휴대폰 연결/재연결 검증은 실행하지 못했습니다. 현재 로컬 로그에는 사용자가
  보고한 단절 상황이 없으며 연결된 ADB 휴대폰도 없습니다. 위 객체 재활성화 검사는
  제어된 테스트 객체를 사용합니다. 사용자 PC에서 동일한 원인이 발생했음을 입증하지 않습니다.
- 기존 OS 키 주입 검사의 실패 기록은 [1.0.9 문서](LINKO-1.0.9.md)에 보존합니다.

## 설치 및 다음 확인

PC의 기존 LINKO를 트레이에서 종료하고 1.0.11 EXE로 교체합니다. Android APK도 함께
덮어 설치할 수 있습니다. 기존 페어링은 먼저 유지합니다. 이번 세션 수정은 PC에 적용됩니다.
휴대폰에서 다시 연결한 뒤 PC의 키보드/마우스 표시를 확인합니다.

문제가 남으면 멈춘 상태에서 **Bluetooth 다시 검사**의 키보드/마우스 세 줄과
**도움말 → 상세 로그 보기 → 진단 파일 저장**의 결과를 확인해야 합니다.
`OS 구독=0`과 `OS 구독>0, 활성=0`은 구독 미복구와 세션 상태 불일치를 구분하는 단서입니다.
필요하면 휴대폰 앱의 **설정 → 도움말 → 연결 진단 로그 공유**와 시각을 맞춥니다.

API 참고: [SubscribedClients](https://learn.microsoft.com/en-us/uwp/api/windows.devices.bluetooth.genericattributeprofile.gattlocalcharacteristic.subscribedclients),
[GattSession](https://learn.microsoft.com/en-us/uwp/api/windows.devices.bluetooth.genericattributeprofile.gattsession).
